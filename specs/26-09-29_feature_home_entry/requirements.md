# 요구사항: 홈 진입 화면

## 목적

앱을 처음 여는 사용자가 냉털픽의 쓰임을 이해하고, 재료 선택을 시작할 수 있게 한다. 앱의 제품 목표와 사용자는 [`../mission.md`](../mission.md)를 따른다.

## 범위

### 포함

- 샘플 시작 화면을 냉털픽 홈 화면으로 교체한다.
- Toss Design System Mobile의 컴포넌트와 시각 기준으로 홈 화면을 구성한다.
- 홈의 주요 버튼에서 재료 선택 안내용 화면으로 이동한다.
- 안내 화면에서 홈으로 돌아올 수 있다.
- 현재 샘플의 광고 테스트 진입점을 사용자 홈 흐름에서 제거한다.

### 제외

- 실제 재료 목록·카테고리·선택 상태
- 메뉴/레시피 데이터와 추천 로직
- 결과 화면, 다시 뽑기, 초기화
- 서버, 계정, 저장 기능
- 앱인토스 권한 추가

## 기능 요구사항

| ID | 요구사항 | 완료 조건 |
| --- | --- | --- |
| HOME-01 | 홈 화면에 서비스명 `냉털픽`을 표시한다. | 초기 실행 시 냉털픽 홈이 기본 화면으로 나온다. |
| HOME-02 | 홈 화면에 재료로 오늘 메뉴를 고른다는 목적을 짧게 설명한다. | 제목과 보조 설명만 읽어도 앱의 목적을 이해할 수 있다. |
| HOME-03 | 주요 동작은 `재료 고르기`로 표시한다. | 화면에서 가장 눈에 띄는 단일 주요 버튼으로 제공한다. |
| HOME-04 | 주요 버튼을 누르면 재료 선택 안내 화면으로 이동한다. | 빈 기능임을 안내하고 홈으로 돌아올 수 있다. 실제 재료 선택은 이 기능 범위 밖이다. |
| HOME-05 | 샘플 광고 테스트 버튼을 제품 홈에 노출하지 않는다. | 초기 화면에서 광고 샘플 문구와 진입 버튼이 보이지 않는다. |
| HOME-06 | 홈과 안내 화면은 TDS Mobile 기본 구성요소를 사용한다. | 제목·본문·주요 버튼에 TDS 컴포넌트를 사용하고, 같은 UI를 임의 CSS로 다시 만들지 않는다. |
| HOME-07 | 좁은 모바일 폭에서 화면과 버튼이 잘리지 않는다. | 320 CSS px 이상에서 가로 스크롤 없이 제목, 설명, 버튼을 사용할 수 있다. |
| HOME-08 | 버튼은 웹의 의미 있는 버튼 요소이며 키보드로 사용할 수 있다. | Tab으로 포커스하고 Enter/Space로 실행할 수 있다. |

## 제안 문구

- 제목: **냉장고 속 재료로 오늘 메뉴를 골라보세요**
- 설명: **있는 재료를 고르면 만들기 좋은 메뉴를 추천해요.**
- 주요 버튼: **재료 고르기**
- 안내 화면 제목: **재료 선택 화면을 준비하고 있어요**
- 안내 화면 버튼: **홈으로**

문구는 MVP 목적을 설명하는 초안이며, 화면 구현 전에 UX 라이팅 검토로 조정할 수 있다.

## 완료 조건

- 기본 진입 화면이 Toss UI 기반 냉털픽 홈이다.
- 사용자가 홈과 재료 선택 안내 화면 사이를 오갈 수 있다.
- 제품 화면에서 샘플 광고 테스트 진입점이 사라진다.
- TDS React 호환성 결정, `npm run lint`, `npm run build`, 모바일 화면 검증을 마친다.
