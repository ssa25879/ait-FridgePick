# 요구사항

로드맵 연결: 로드맵 13단계 RSC-05 잔여 "미지원 필수 재료 보완" (RGC 후속).

| ID | 요구사항 | 완료 조건 |
| --- | --- | --- |
| UIM-01 | 상위 미지원 이름을 처리 방식(별칭·새 선택 재료·새 양념 재료·육수류·모호)으로 분류하고 근거를 남긴다 | [설계의 분류표](./design.md)가 항목별 근거(원문 사례)를 담는다. 분류 없는 이름은 매핑하지 않는다 |
| UIM-02 | 별칭은 뜻이 같은 이름에만 추가한다 | 각 별칭은 실제 원문 사례로 같은 재료임을 확인한다. 재료 일부(예: 노른자)나 다른 재료를 하나로 합치는 경우는 결정 기록에 이유를 남긴다 |
| UIM-03 | 새 선택 재료는 사용자 승인 후 배치로 추가한다 | 배치마다 추가 목록·카테고리·예상 효과를 사용자가 승인한 뒤에만 `ingredients.ts`에 넣는다 |
| UIM-04 | 새로 추가하는 양념류는 가정 대상이 아니다 | 가정 기본 양념 9개 목록(`ASSUMED_SEASONING_IDS`)을 바꾸지 않는다. 새 양념류는 선택해야 보유로 계산된다 |
| UIM-05 | 모호한 이름은 일괄 별칭으로 처리하지 않는다 | 호박·기름 등은 레시피별 원문 확인 후 레시피 단위 보정으로만 매핑한다 |
| UIM-06 | 육수류는 사용자 결정 전까지 현재 동작(미지원 유지)을 유지한다 | 결정 1번 확정 전에는 육수·닭육수·다시물·쌀뜨물·물전분을 매핑하지 않는다 |
| UIM-07 | 매핑 외 추천 규칙은 바꾸지 않는다 | 60% 기준·준비 완료 판정·정렬 코드는 변경하지 않는다. 후보 집합 변화는 매핑에 따른 결과로만 발생한다 |
| UIM-08 | 원문은 보존한다 | `sourceIngredientText`·분량·단계·출처는 수정하지 않는다 |
| UIM-09 | 배치마다 전후를 측정하고 기록한다 | 준비 가능 레시피 수(미지원·안내 없음), 합성 냉장고 준비 완료 평균, 후보 수, 재료 수, 테스트 개수를 기록한다. 합성 결과를 실사용 효과로 일반화하지 않는다 |

## 비기능

- 320×640에서 재료 칩 목록·배너·CTA가 겹치지 않는다. 칩이 늘어도 기존 가로 넘침 없음 조건을 유지한다.
- 재료 개수를 기대값으로 쓰는 테스트·문서(현재 126개)를 함께 갱신한다.
- AGENTS.md 하드 규칙(텍스트 크기·터치 타깃·한글 줄바꿈)은 그대로 적용한다.
