# 결정 기록: 사용자 상태 저장·복원

| 결정 | 근거 | 요구사항/제한 |
| --- | --- | --- |
| User.getAnonymousKey HASH 사용 | 서버·로그인 없이 공식 사용자 식별, isSupported는 설치 SDK3.2.0으로 확인 | USP-01·03. 공용 fallback 없음 |
| SDK Storage 비동기 API | 직접 브라우저 localStorage는 네이티브 계약과 다름 | USP-02·04. 저장 대상은 재료·필터만 |
| 초기 조회1500ms 제한 | 조회가 UI 사용을 막지 않음 | USP-06. 시간 초과 해당 마운트는 세션만 사용 |
| 읽기 실패와 빈 저장소 분리 | 실패한 조회 뒤 기본값 저장으로 기존 데이터 소실 방지 | USP-05·06 |
| 사용자 입력/추천 우선 | 늦은 복원이 현재 선택과 이미 계산한 추천을 불일치시키지 않음 | USP-05. 일부 직접 조합 테스트 미실행 |
| 사용자별 쓰기 직렬화·읽기 대기 | 느린 과거 쓰기와 재마운트 경합 방지 | USP-07. 종료 직전 완료/멈춘 저장은 보장 못 함 |
| 홈에서 플랫폼 이벤트 미구독 | 기본 종료 동작 보존 | USP-08·09. 실제 Android 전달은 기기 QA |

미확정: 같은 WebView 생존 중 계정 변경, 즉시 종료 시 마지막 쓰기 보존, 실제 HASH 안정성. USP-10 및 [상위 검증](../26-10-02_feature_release_checklist_readiness/validation.md)에서 확인한다. 새 서버/계정/권한/상태 라이브러리는 추가하지 않는다.
