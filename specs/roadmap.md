# 냉털픽 로드맵

이 문서는 앱인토스 미니앱 기획서의 MVP 범위를 작고 확인 가능한 작업으로 나눈다. 체크 항목은 구현 순서이며, 기능을 완료했다고 표시하려면 각 항목의 완료 기준을 확인한다.

## 현재 상태

2026-10-04 코드 대조: 재료 95개, 공식 레시피 888개(수기20개 교체·중복 제외), React 18.3.1. 과거 재료 100개 표기는 정정한다. 기능 구현·자동 테스트와 출시 검증을 구분하며 문서의 과거 기기 확인은 당시 번들에 한정된다. 상세 기준은 [문서 안내](./README.md), 현재 작업은 [상태 저장·복원](./26-10-04_feature_user_state_persistence/README.md)을 따른다.


- React·TypeScript·Vite 기반 프로젝트와 앱인토스 빌드 설정이 있다.
- `src/App.tsx`는 홈·재료 선택·결과 화면을 전환한다. 추천 결과 계산, 레시피 상세, 빈 상태, 처음부터 초기화와 화면 왕복 흐름을 구현했다.
- 2단계 재료 카탈로그·선택 기능을 완료했다. 다섯 카테고리, 선택 요약, AIT DevTools 320×640 CSS px 확인을 제공한다. 8단계에서 카탈로그를 28개에서 95개로 확장했다.
- 3단계 레시피 데이터를 완료했다. 로컬 레시피 20개와 타입을 추가하고 기존 28개 재료 카탈로그 ID, 필수 재료 수, 조리 단계, 난이도를 자동 검증한다.
- 1·4·5·6단계 기능 구현, 20개 자동 테스트, 320×640 모바일 확인과 세 관점 심층 코드 리뷰를 마쳤다. 사용자가 실제 앱인토스 미니앱에서 재료 선택부터 결과까지 한 사이클이 정상 작동함을 확인해 7단계 검증도 완료했다.
- 8단계 CSV 카탈로그 확장: 1,156개 중 888개를 추가해 전체 908개 레시피를 제공한다. 자동 테스트 51개, TypeScript, lint, Vite/AIT build와 AIT DevTools 320×640 흐름을 확인했다. 원문 조리 단계 6,717개 중 17개에 붙은 표시용 접미를 정리했고 숫자로 시작하는 재료명과 필수 양념 분류를 보완했다. 대표 재료 묶음의 후보 없음은 3/10으로 기존·통합이 같고, 재계산한 고정 seed 합성 표본 100개에서는 94%에서 89%로 줄었다. 실제 이용자 분포 검증은 아니므로 추천 공백 해결을 보장하지 않는다. 자세한 결과는 [`26-09-29_feature_public_recipe_catalog/validation.md`](./26-09-29_feature_public_recipe_catalog/validation.md)에 기록했다.
- 9단계 추천 필터를 구현했다. 매칭률은 기본 60%, 60~100%·5% 단위로 조절하며 난이도는 단계·전체 필수 재료 수로 추정한다. 전체 레시피 908개는 쉬움 125, 보통 336, 어려움 447개로 분류됐다. 320×640 AIT DevTools 화면에서 필터와 CSV 레시피 출처 각주를 확인했다. 자세한 결과는 [`26-10-02_feature_recommendation_filters/validation.md`](./26-10-02_feature_recommendation_filters/validation.md)에 기록한다.
- 프로젝트 기획서는 [`NaengteolPick_React_Project_Plan.md`](./NaengteolPick_React_Project_Plan.md)에 둔다.

## 9단계: 추천 매칭률·난이도 필터와 출처 각주

- [x] 재료 선택 화면에 전체·쉬움·보통·어려움 난이도 필터를 추가하고 선택한 난이도를 후보 계산에 적용한다.
- [x] 매칭률·난이도 조합, 난이도 판정 경계, 빈 후보와 기본값 복원을 자동 검증한다.
- [x] 공개 레시피 정적 카탈로그를 새 판정 규칙으로 다시 생성하고 수기·공개 레시피 간 규칙 일관성을 확인한다.
- [x] 결과 화면의 제공기관·데이터셋·원본 ID 출처 표기를 조리 정보 아래의 작은 각주로 옮긴다.
