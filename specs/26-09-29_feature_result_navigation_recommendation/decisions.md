# 결정 기록: 추천 결과 흐름과 메뉴 후보 계산

## 확정 사항

### 1. 후보 기준은 60% 이상

- 결정: 필수 재료 매칭률 `matched / required`가 `0.6` 이상이면 후보에 포함한다.
- 근거: 프로젝트 기획서의 초기 제안값을 4단계 구현 기준으로 확정한다. 비율을 정수로 반올림한 뒤 비교하지 않아 경계가 명확하다.

### 2. 선택 재료 계산은 필수 재료에 한정

- 결정: `optionalIngredients`는 매칭률이나 후보 판정에 반영하지 않는다.
- 근거: 로드맵의 매칭 기준은 레시피 필수 재료와의 교집합이다. 선택 재료는 후속 결과 화면에서 보유 재료로 활용할 수 있다.

### 3. 결과에서 홈으로 가도 선택 상태를 유지

- 결정: `홈으로`는 화면 상태만 바꾼다. 선택 재료를 지우는 `처음부터` 기능은 5단계로 남긴다.
- 근거: 1단계는 결과에서 첫 화면으로 돌아가는 동작만 요구하고, 5단계가 초기화 동작을 별도 정의한다.

### 4. 결과 화면은 상세 안내 제공

- 결정: 추천 메뉴명, 매칭률, 보유·부족 재료 이름, 조리 순서, 다시 뽑기, 처음부터 초기화, 빈 상태 안내와 홈 이동을 구현한다.
- 근거: 사용자가 6단계까지 연속 진행하도록 범위를 넓혔다.

### 5. 단일 후보와 빈 재료 안내

- 결정: 선택 재료가 0개인 상태와 재료는 선택했지만 후보가 없는 상태를 서로 다른 문구로 안내한다. 후보가 하나면 다시 뽑기를 숨기고 후보가 하나임을 안내한다.
- 근거: 상태별로 가능한 다음 행동이 달라 선택 화면 이동을 구분해야 한다.

### 6. 브랜드 색상

- 결정: AIT 설정의 예시 Toss Blue 기본값을 앱의 중립 어두운 색상 `#191F28`로 바꾼다.
- 근거: 앱 화면이 중립색 버튼을 사용하고 디자인 가이드가 플랫폼 기본 파랑을 브랜드색으로 쓰지 않도록 한다.
