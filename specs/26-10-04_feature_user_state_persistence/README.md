# 사용자 상태 저장·복원과 플랫폼 이동

- 작성일: 2026-10-04
- 브랜치: `feature/user-state-persistence`
- 상태: 문서·코드·자동 테스트·브라우저 mock 검증 완료, 실기기 QA 대기
- 요청: specs 정합성 개선 후 감사 보고의 보완내용 1번 진행
- 상위 요구사항: RCR-01~03, RCR-07의 뒤로가기·홈 이벤트 연결

서버·로그인 없이 사용자별로 선택 재료·매칭률·난이도를 보존한다. 앱을 다시 열면 홈부터 시작하고 저장한 선택을 재사용한다. SDK 실패가 추천을 막거나 다른 사용자의 데이터를 대신 읽는 일이 없어야 한다.

이 작업에는 광고 위치 변경, 화면 확대 제한, 실제 광고 ID 이전, 콘솔 업로드·출시를 포함하지 않는다. 네이티브 동작은 자동 테스트와 실제 토스 앱 QA를 구분한다.
