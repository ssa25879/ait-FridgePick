# 요구사항

## RSC-13 기기 피드백: 조리 단계 누락 재료

사용자 승인으로 조리 단계에서 실제 사용이 확인된 재료를 합성 카탈로그의 필요 재료에 추가한다. 선택 가능한 재료는 보유 여부를 계산하고,미지원 이름은 추가 준비 목록에 표시한다. 원문 분량·단계·출처는 보존하며 미확정 종류/구성/분량의 안내와 준비 완료 차단을 유지한다. RSC-12의 원문 보존은 유지하되 앱의 requiredIngredients/unmappedRequiredIngredients 불변 방침은 대체한다. [설계·범위·검증](./step-required-ingredients.md).

RSC-12: 실제 EPIS 재료·과정 원본과 복구한 식약처 CSV를 대조해 확인된 불일치에 검토 안내를 부착하고 준비 완료에서 제외한다. 원문 데이터·필수 목록·분량을 추정 수정하지 않는다. 직접 만든 육수·제거한 전분·팁 대체법을 자동 누락으로 판정하지 않는다. 점검 범위와 미검증 범위를 [EPIS 대조](./ingredient-review.md)와 [식약처 대조](./mfds-ingredient-review.md)에 기록한다.

| ID | 완료 조건 |
| --- | --- |
| RSC-01 | 수기20개를 공식 원문 이름·분량·조리 순서·출처를 가진20개 메뉴로 교체하고 전체 카탈로그에 같은 ID를 중복 등록하지 않는다. |
| RSC-02 | 모든 추천 레시피에 비어 있지 않은 원문 분량과 출처가 있다. 임의로 g·인분을 추정하거나 미지원 필수 재료를 숨기지 않는다. |
| RSC-03 | 제품 카탈로그로 후보를 계산해 결과의 분량·출처·단일 검색 수 표시를 확인한다. 기존 상태·화면 테스트용 수기 데이터는 test/fixtures에 격리하고 제품에서 참조하지 않는다. |
| RSC-04 | 공식 전체 자료의 이름·재료 분량·조리과정·이용 조건·확보일을 확보하고 출처 ID로 결합한다. 원본 보존·누락/중복/제외 사유·재생성 방법을 기록한다. 샘플 확인만으로 완료하지 않는다. |
| RSC-05 | 현재 대표10조합 기준선을 실제 getRecipeCandidates로 재검증하고 추가 전후 후보 수·무결과율·미지원 필수 재료 수를 비교한다. 추천되는 조합 수가 증가하고 새 후보의 원문 분량·조리법·출처 표시를 확인해야 완료한다. |
| RSC-06 | 원본에 실제 존재하는 명확한 동의어·표기를 기존 선택 재료에 연결한다. 모호한 재료는 보존하고 원문 분량/순서·필수 재료 규칙·60% 조건을 유지한다. 재생성한 실제 데이터로 선택 가능한 필수 재료와 후보 수의 전후 결과를 기록한다. |
| RSC-07 | 생성 파일에 미지원으로 남았지만 현재 매핑 함수가 인식하는 필수 재료를 합성 카탈로그에서 갱신한다. 원본 생성 파일·분량·단계·출처를 수정하지 않고 모호한 재료는 계속 표시한다. 매칭60%와 기존 난이도 판정 규칙을 유지하며 대표10조합 및 전체 선택100% 후보를 비교한다. |
| RSC-08 | 사용자 선택인 주재료 중심 매칭을 적용한다. 원문 주재료 구분을 우선하고, 구분이 없으면 등록 양념을 제외한 필수 식재료로 계산한다. 미지원 주재료는 분모에 유지한다. 전체 부족 재료·분량·출처·난이도를 보존하고 대표10조합 무결과율 및 주재료100%의 안내를 검증한다. |
| RSC-09 | Node24.19.0을 고정하고 잠금 파일 기반 설치·테스트·기본 빌드 CI 및 실제 프로젝트 README를 준비한다. 식약처 원본 미확보를 명시하고 생성기에 원본SHA256·확보일을 추가한다. 확보일과 데이터 기준일을 혼동하지 않고 현재 공식 데이터 파일을 바꾸지 않는다. |
| RSC-10 | 로드맵13단계의 초기로딩 개선: 홈의 추천 모듈 정적 import를 제거하고 재료 선택 진입에서 지연 로드한다. 로딩 실패·중복 추천·입력/필터 변경·초기화·플랫폼 이동·언마운트 이후 늦은 완료를 안전하게 처리한다. 일반빌드와AIT의청크분리·원문보존·회귀검사를확인하고실기기전후측정은마지막통합검증에남긴다. |

2026-10-05 사용자 답변 “주재료 중심 매칭으로 개선”에 따라 RSC-08이 기존 RSC-05~07의 전체 필수 재료 매칭 분모 유지 방침을 대체한다. 기본 최소60%는 유지하며 양념을 자동 보유 처리하지 않는다.

RSC-11: 사용자 선택 “바로 만들 수 있는 메뉴 우선 + 부족한 메뉴는 별도 표시”에 따라 모든 등록 필수 재료를 보유하고 미지원 필수 재료가 없는 후보를 우선 추천한다. 준비 필요 후보는 별도 그룹·개수·명시적 안내로 표시하고 다시 뽑기는 선택 그룹에 한정한다. 준비 완료0개도 명시하며 보유 분량을 확인했다고 주장하지 않는다. 주재료 매칭률과 조리 준비 상태는 별개다.
