# 요구사항

로드맵 연결: 로드맵 13단계 RSC-05 잔여("추천 공백 보완")와 사용자 실기기 피드백(2026-10-20). 아래 ID는 이 문서 기준이다.

| ID | 요구사항 | 완료 조건 |
| --- | --- | --- |
| SAS-01 | 양념 카테고리 재료는 사용자가 선택하지 않아도 있다고 가정해 준비 완료 판정에서 제외한다 | 양념을 하나도 고르지 않아도, 레시피의 양념 외 필수 재료를 모두 선택했고 미지원 재료·원문 확인 안내가 없으면 준비 완료다 |
| SAS-02 | 후보 집합과 매칭률은 바꾸지 않는다 | 같은 입력에서 후보 목록(레시피 ID 집합)과 `matchRate`가 변경 전과 같다 |
| SAS-03 | 부족 재료 수에 따른 정렬은 양념을 제외한다 | `getMissingIngredientCount`가 가정한 양념을 세지 않는다. 양념만 부족한 레시피와 아무것도 부족하지 않은 레시피의 부족 수가 같다 |
| SAS-04 | 결과 화면에 "양념 확인"을 따로 보여준다 | 사용자가 선택하지 않은 필수 양념 이름이 가나다 순으로 나온다. 없으면 이 구역을 숨긴다 |
| SAS-05 | "더 준비할 재료"는 양념을 제외한다 | 양념은 "양념 확인"에만 나오고 두 구역에 중복되지 않는다 |
| SAS-06 | 미지원 필수 재료·원문 확인 안내가 있는 레시피는 계속 준비 완료가 아니다 | 기존 판정 조건이 그대로 유지된다 |
| SAS-07 | 재료 선택 화면의 양념 카테고리에 가정 안내를 보인다 | "선택하지 않아도 집에 있다고 가정해요"에 해당하는 문구가 양념 카테고리를 볼 때 보인다 |
| SAS-08 | 가정 범위는 한 곳에서 정의한다 | 가정 대상 ID 집합이 한 상수·함수에서만 정의되고 판정·정렬·표시가 그것을 쓴다 |

## 비기능

- 11px 이하 텍스트 금지, 본문 15px 이상, 터치 타깃 44px 이상, 한글 `word-break: keep-all` (AGENTS.md 하드 규칙).
- 새 안내 문구는 해요체이고 이모지·느낌표를 쓰지 않는다.
- 기존 동작 보존: 재실행 시 선택 초기화, 광고 배치, 공유·리뷰·측정 이벤트.
