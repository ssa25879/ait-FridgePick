# 검증 계획: 식품안전나라 레시피 CSV 카탈로그

## 기준 상태

- 현재 앱에는 로컬 레시피 20개, 재료 카탈로그 28개가 있다.
- 이 명세 단계에서는 데이터, 코드, 의존성을 수정하거나 테스트를 실행하지 않았다.
- 실제 CSV, 이용 조건, 정규화 건수는 확인 전이다.

## 비교 기준

비교 입력은 현재 28개 재료 카탈로그에서 실제 냉장고 조합을 대표하도록 정하고, 원본·확장 데이터에 똑같이 적용한다. 입력별 후보 수와 후보 없음 여부를 기록한다. 데이터가 늘었다는 사실만으로 추천 품질이 개선됐다고 보지 않는다.

실제 CSV를 본 뒤 입력 사례 수와 포함 데이터 규모를 정하고, 구현 계획에 고정한다.

## 실행 결과

- 수행한 검증: 문서와 기존 코드의 데이터 모델 및 추천 계산 흐름 확인, 공식 출처의 CSV 제공 필드·다운로드 제한·파일 주소 표기 확인.
- 수행하지 않은 검증: 실제 인증 CSV 취득·파싱, 데이터 재사용 권리 확인, 자동 테스트, lint, Vite·AIT build, AIT DevTools·Toss 환경에서 UI·모바일 실행.
