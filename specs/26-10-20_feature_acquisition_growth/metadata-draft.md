# 콘솔 메타데이터 수정안 (적용 전 초안)

2단계(ACQ-03) 산출물이다. **콘솔에는 적용하지 않았다.** 적용은 공개 내용 변경이므로 사용자 승인 후 진행한다. 현재 값은 2026-10-20 `miniapp_get` 조회 기준이다.

## 부제 (20자 이내, 느낌표·비속어 불가)

| 구분 | 문구 | 글자 수 |
| --- | --- | --- |
| 현재 | 냉장고 재료로 오늘 메뉴 찾기 | 16 |
| 제안 | 남은 재료로 오늘 메뉴 정하기 | 16 |

근거: "남은 재료"는 냉털(냉장고 털기)의 의미를 직접 설명하고, "정하기"는 앱의 핵심 가치(결정을 가볍게)와 맞다. 검색량 데이터는 없어 효과는 추정이다.

## 키워드

현재 6개: 냉털픽, 냉장고, 재료, 식재료, 요리, 음식. 허용 최대 개수는 미확인이다.

| 후보 | 이유 | 상태 |
| --- | --- | --- |
| 레시피 | 요리 검색의 기본 표현 | 추가 후보 |
| 냉장고파먹기 | 같은 행동을 가리키는 흔한 표현 | 추가 후보 |
| 냉파 | 위의 줄임말 | 추가 후보 |
| 오늘뭐먹지 | 메뉴 결정 의도의 검색 표현 | 추가 후보 |
| 메뉴추천 | 앱 기능 그대로 | 추가 후보 |
| 남은재료 | 부제와 일관 | 추가 후보 |
| 자취요리 | 주요 사용자(1인 가구) 표현 | 추가 후보 |
| 식재료, 음식 | 범위가 넓어 경쟁이 크고 의도가 약함 | 교체 후보 |

실제 검색어 통계를 확인할 수단이 없으므로 위 후보는 가설이다. 적용 후 검색 유입을 비교한다.

## 상세 설명 (500자 이내, 이모지 없음)

제안:

> 냉털픽은 냉장고에 남은 재료를 고르면 지금 만들기 좋은 메뉴를 하나 골라 알려주는 앱이에요. 재료를 카테고리별로 고르고 메뉴 뽑기를 누르면, 선택한 재료로 바로 만들 수 있는 메뉴를 먼저 보여줘요. 재료가 조금 모자란 메뉴는 따로 안내하고 더 준비할 재료를 알려줘요. 마음에 들지 않으면 같은 재료로 다시 뽑을 수 있어요. 난이도와 재료 매칭률로 후보를 좁힐 수 있고, 원문 재료 분량과 조리 순서, 출처도 확인할 수 있어요. 선택한 재료와 설정은 앱을 실행하는 동안 유지되고, 다시 실행하면 처음부터 시작해요.

변경 이유: 현재 문장은 내부 동작(필요 재료 기준, 원문 확인 안내)이 먼저 나오고 "초기화됩니다"로 끝난다. 가치를 먼저, 제약은 마지막에 둔다. 현재 정책(실행 중 유지·재실행 초기화)과 사실이 일치한다.

## 적용 전 확인할 것

- 글자 수 검사(2026-10-20): 부제 16자, 상세 설명 286자(500자 이내), 이모지·느낌표 없음.
- 콘솔 변경은 검수 재요청이 필요할 수 있다. 영향은 미확인이다.
- 변경 날짜를 기록해 이후 검색 유입을 비교한다(TASK-08).
