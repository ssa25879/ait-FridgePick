## 후속 범위: 실제 추천 가능한 레시피 확장

2026-10-05 사용자 요청으로 로드맵13단계의 추가 자료 확보·추천 공백 분석을 RSC-04~05로 준비한다. 기존 브랜치와 문서를 재사용한다. [자료 확보 안내](./acquisition.md)를 따른다. 자료 확보·편입·품질 개선은 아직 미완료다.

후속 구현: 기본537개/재료6104행/과정3022행을 결합해 EPIS467개를 추가했다. 전체 카탈로그1355개, 대표10조합 무후보10/10→9/10. 원문 분량 누락3개·조리 순서 오류3개·낮은 매핑63개·매핑 재료 없음1개를 제외했다. 자동119개 테스트와 기본/출시 빌드 통과. 새 데이터의 기기 QA·커밋/푸시·번들 업로드는 미수행이다. 추가 확보가 추천 공백을 모두 해결한 것은 아니다.

이후 사용자 승인으로6f6d70e를 기능 브랜치에 커밋·푸시하고 원격 SHA 일치를 확인했다. 이어서 RSC-06의 명확한10개 표기를 보완해 EPIS471개/전체1359개로 재생성했다. EPIS의 필수 재료가 모두 매핑된 메뉴60→70개, 대표10조합의 무후보9/10 유지. RSC-06 변경은 현재 미커밋이다.
