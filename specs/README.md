## 완료 표시 기준

1. 구현 완료: 코드와 요구사항의 대응이 존재한다.
2. 자동 검증 완료: 실행 명령, 결과, 실제 테스트 범위가 기록되어 있다.
3. 기기 검증 완료: 토스 앱 버전/OS/번들/시나리오/결과가 기록되어 있다.
4. 출시 완료: 약관·최초 검수·라이브 배포 상태까지 확인했다.

상위 단계의 증거 없이 하위 단계 결과를 확대 해석하지 않는다. 실제 광고 ID와 사용자 식별키는 문서·로그에 복사하지 않는다. 작업 로그는 사용자의 ‘로그 생략’ 선택을 따른다. 후속 요약은 루트 `Task.md`로 연결한다.
