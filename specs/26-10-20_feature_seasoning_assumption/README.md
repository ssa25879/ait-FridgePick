# 양념 보유 가정 (준비 완료 판정 변경)

실사용에서 "바로 만들 수 있는 메뉴"가 거의 나오지 않는 문제를 해결한다. 원인은 레시피 수가 아니라 판정 규칙이다. 현재는 레시피의 필수 재료에 들어 있는 **양념까지 사용자가 직접 선택해야** 준비 완료가 된다. **기본 양념 9개**(소금·설탕·후추·식용유·간장·참기름·고춧가루·참깨·식초)는 집에 있다고 가정하고, 선택하지 않은 필수 기본 양념은 결과 화면에서 따로 안내한다. 처음에는 양념 카테고리 전체를 가정하는 설계였으나 2026-10-20 사용자 결정으로 기본 양념만으로 좁혔다.

- 브랜치: `feature/seasoning-assumption` (기준 `feature/acquisition-growth` af3d553)
- 상태: **로컬 구현·자동 검증·브라우저 모의 확인 완료. 번들 업로드·실기기 확인·출시는 하지 않았다.** 결과는 [검증](./validation.md).
- 요청: 2026-10-20 사용자 — 준비 완료 판정에서 양념을 있다고 가정하고 부족한 양념은 결과에 별도 안내. 이후 가정 범위를 기본 양념 9개로 좁히라고 결정.
- 관련: [추천 공백 보완](../26-10-12_feature_recommendation_gap_coverage/README.md), [검색 정확도 향상](../26-10-12_feature_recipe_search_accuracy/README.md), [유입 개선](../26-10-20_feature_acquisition_growth/README.md)

## 왜 필요한가 (2026-10-20 합성 측정, 실사용 데이터 아님)

레시피 1,359개를 대상으로 레시피 사용 빈도에 비례해 무작위로 만든 냉장고(양념 제외)로 현재 규칙의 준비 완료 수를 쟀다.

| 선택한 재료 수 | 현재 규칙: 평균 준비 완료 / 0개인 비율 | 기본 양념 9개 가정(예측) | 참고: 양념 33개 전체 가정 |
| --- | --- | --- | --- |
| 5 | 0.0 / 99% | 1.0 / 30% | 1.2 / 25% |
| 8 | 0.0 / 98% | 1.7 / 12% | 2.2 / 7% |
| 12 | 0.1 / 93% | 2.8 / 4% | 3.9 / 2% |
| 16 | 0.1 / 89% | 4.6 / 1% | 6.9 / 0% |

- 레시피 필수 재료에서 가장 많이 쓰이는 것이 소금(719)·마늘(707)·후추(540)·대파(509)·간장(508)·설탕(427)·식용유(412)·참기름(364)이다. 마늘·대파는 채소 카테고리라 이번 가정 대상이 아니다(재료 선택 화면에서 직접 골라야 한다).
- 이 규칙을 바꿔도 **한계가 남는다**: 1,359개 중 1,120개(82%)는 지원하지 않는 필수 재료(육수 53, 기름 32, 호박 21 …)가 있어 어떤 냉장고로도 준비 완료가 될 수 없다. 준비 가능한 레시피(미지원 재료·원문 안내 없음)는 215개이고, 그중 필수 양념이 모두 기본 양념 9개 안에 있는 것은 110개다. 상위 100개 미지원 재료까지 매핑하면 401개가 된다(후속 범위).
- 합성 냉장고는 실제 사용자 선택이 아니다. 효과는 구현 후 실기기·실사용으로 다시 확인해야 한다.
