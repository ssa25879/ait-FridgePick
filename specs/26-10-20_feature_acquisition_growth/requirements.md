# 요구사항

| ID | 요구사항 | 완료 조건 | 로드맵·근거 |
| --- | --- | --- | --- |
| ACQ-01 | 퍼널을 측정한다: 진입 → 재료 선택 시작 → 추천 결과 노출 → 다시 뽑기 → 공유 | 각 단계 이벤트가 기록되고 콘솔 이벤트 로그에서 단계별 수를 확인한다. 개인 식별 정보는 기록하지 않는다 | 추천 미니앱 기준 2(실사용 지표) |
| ACQ-02 | 콘솔에 전환 지표를 등록한다 | 주요 행동을 "추천 결과 노출"로 정하고 전환 지표로 등록, 1일 뒤 값이 채워지는지 확인한다 | 위와 동일 |
| ACQ-03 | 검색 노출 메타데이터를 개선한다 | 부제(20자 이내·느낌표 없음), 키워드, 상세 설명이 사용자 검색 표현과 앱의 실제 동작을 모두 반영한다 | 콘솔 등록 안내 |
| ACQ-04 | (취소) 앱 연령 제한 재검토 | 미니앱은 19세 이상에게 배포되는 플랫폼 조건이라는 사용자 정정으로 제외한다. ID는 유지한다 | 2026-10-20 사용자 정정 |
| ACQ-05 | 추천 결과를 공유할 수 있다 | 결과 화면에서 공유하면 토스 공유 링크가 만들어져 받는 사람이 앱 첫 화면으로 들어온다. 로그인 없이 동작한다 | 공유 SDK |
| ACQ-06 | 공유 문구·미리보기 이미지가 외부 광고 가이드를 따른다 | "토스 공식 파트너" 등 금지 표현이 없고 OG 이미지는 https 절대 경로다 | 외부 광고 가이드 |
| ACQ-07 | 리뷰를 쌓을 근거를 만든다 | 만족 시점(결과 확인 후)에만 리뷰 요청을 보이고 반복 요청하지 않는다 | 추천 미니앱 기준 3 |
| ACQ-08 | 재방문 장치는 UX 원칙을 지킨다 | 첫 진입에 로그인·알림 동의를 요구하지 않는다. 알림은 사용자가 원할 때만 요청한다 | 추천 미니앱 기준 1 |
| ACQ-09 | 효과를 정직하게 판단한다 | 표본이 작을 때 비율로 성공을 선언하지 않고, 변경 전후 기간·표본 수를 함께 기록한다 | 이 문서 현황 |

## 수치 목표

현재 표본(고유 약 5명)으로는 의미 있는 기준선이 없다. 목표 수치는 [결정·미확정](./decisions.md) 1번에서 사용자가 정한다. 이 문서는 임의 수치를 목표로 고정하지 않는다.
