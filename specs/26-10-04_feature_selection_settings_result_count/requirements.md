# 요구사항

| ID | 요구사항·완료 조건 |
| --- | --- |
| SSC-01 | 재료 화면에 자동 저장 안내를 표시한다. 준비·저장 중·완료·실패·세션 유지 상태를 실제 결과와 구분하고 실패를 성공으로 표시하지 않는다. |
| SSC-02 | 재료 화면에서 재료·필터 초기화를 요청할 수 있다. 확인 전 변경하지 않고 취소는 입력을 유지한다. 확인 시 재료0개/최소60%/난이도전체로 바꾸고 같은 사용자 저장값에 반영한다. |
| SSC-03 | 초기화 후 재진입과 늦은 복원에서도 초기화 상태를 유지한다. 미지원·실패 시 현재 실행의 추천은 계속 사용할 수 있다. |
| SSC-04 | 결과 내용 하단·동작 버튼 위에 필터 적용 후보 수로 “레시피가 N개 검색되었습니다”를 한 번만 표시한다.0개/1개에 대한 기존 별도 안내와 중복하지 않는다. 전체 카탈로그 수가 아니며 다시 뽑기는 후보 수를 바꾸지 않는다. |
| SSC-05 | 홈 꾸밈은 보류한다. 기존 CTA·광고 스크롤 조건·32px 간격을 유지하고 새로운 안내·버튼은 좁은 화면에서 겹치지 않는다. 새 빌드 기기 확인은 별도로 남긴다. |
| SSC-06 | 재료 카테고리에 전체 탭을 추가해95개 재료를 중복 없이 표시한다. 탭 이동 후 재료 선택을 유지하며 기본 탭은 기존 채소·과일이다. 난이도의 전체 버튼과 접근성 이름을 구분한다. |
| SSC-07 | 필터·저장 설정은 기본 접힘이며 사용자 조작으로 펼친다. 접힌 요약에 현재 매칭률·난이도를 표시하고 접기/펼치기 후 값이 유지된다. 본문15px·터치44px 이상과 광고32px 간격을 유지하며 같은 조건의 기본 화면 스크롤 길이를 줄인다. |
