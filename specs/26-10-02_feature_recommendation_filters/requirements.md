# 요구사항: 추천 필터와 레시피 출처 각주

## 목적

재료 선택에 더해 사용자가 원하는 보유 재료 매칭률과 조리 난이도를 정해 추천 후보를 좁힌다. 출처는 확인 가능하게 유지하면서 결과의 주요 조리 정보보다 시각적으로 덜 두드러지게 표시한다.

## 범위

### 포함

- 재료 선택 화면에서 최소 필수 재료 매칭률을 60~100% 사이 5% 단위로 조절한다. 초기값은 60%다.
- 난이도 판정은 조리 단계 수와 전체 필수 재료 수를 사용하며 `easy | normal | hard` 세 단계로 정한다.
- 수기 레시피와 CSV 공개 레시피가 같은 난이도 판정 규칙을 쓴다.
- 재료 선택 화면에서 `전체 | 쉬움 | 보통 | 어려움` 중 난이도 필터를 선택한다. 초기값은 전체다.
- 추천 후보를 매칭률과 난이도 모두로 필터링한다.
- 결과 화면 하단에 제공기관·데이터셋·원본 ID를 작은 출처 각주로 표시한다.
- 추천 설정은 결과에서 재료 선택으로 돌아올 때 보존하고 `처음부터`를 실행하면 기본값으로 되돌린다.
- 자동 테스트와 앱인토스 화면·빌드를 검증한다.

### 제외

- 조리 시간, 열량, 알레르기·제외 재료 필터
- CSV에 없는 공식 난이도 값의 생성 또는 난이도 정보에 대한 외부 API 연동
- 매칭률에 따른 후보 정렬이나 점수화
- 서버 저장 및 앱 재실행 이후 설정 저장

## 요구사항

| ID | 요구사항 | 완료 조건 |
| --- | --- | --- |
| RF-01 | 매칭률 기준을 조절한다. | 접근 가능한 입력으로 60~100%를 5% 단위로 고르며 기본값은 60%다. |
| RF-02 | 매칭률 기준을 후보 계산에 적용한다. | 계산 비율이 선택한 기준과 같거나 큰 레시피만 후보가 된다. 미지원 필수 재료도 분모에 포함한다. |
| RF-03 | 난이도를 수치 기준으로 계산한다. | 쉬움: 단계·필수 재료 각각 ≤6. 보통: 쉬움이 아니며 각각 ≤10. 어려움: 둘 중 하나 >10. |
| RF-04 | 난이도 선택을 후보 계산에 적용한다. | 기본 전체는 모든 난이도를 허용하고, 개별 난이도는 해당 레시피만 남긴다. |
| RF-05 | 화면 간 추천 설정을 유지한다. | 결과의 재료 수정 화면에서 현재 설정이 보이고, 처음부터 동작은 60%·전체로 되돌린다. |
| RF-06 | 출처를 각주로 표시한다. | 결과 내용 맨 아래에 제공기관, 데이터셋, 원본 ID가 13px 이상의 보조 텍스트로 표시된다. |
| RF-07 | 모바일 조작성을 유지한다. | 320×640 CSS px에서 가로 넘침이 없고 난이도 선택 버튼은 최소 44px 터치 높이를 갖는다. |

## 완료 조건

- `inferRecipeDifficulty`의 세 난이도 경계를 자동 테스트한다.
- 후보 계산에서 60%·중간값·100% 경계, 미지원 필수 재료, 난이도 교집합이 테스트된다.
- 수기 및 공개 카탈로그의 모든 `difficulty` 값이 계산 규칙과 일치한다.
- 앱 흐름 테스트에서 필터 선택·결과 편집 시 보존·처음부터 기본값 복원을 확인한다.
- 결과 출처 각주가 상세 섹션보다 작고 조리 순서 이후에 표시된다.
- 테스트, lint, TypeScript/Vite/AIT build 및 320×640 화면 확인 결과를 기록한다.
