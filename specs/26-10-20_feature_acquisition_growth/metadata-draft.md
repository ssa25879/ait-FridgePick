# 콘솔 메타데이터 수정안 (적용 전 초안)

2단계(ACQ-03) 산출물이다. **콘솔에는 적용하지 않았다.** 적용은 공개 내용 변경이므로 사용자 승인 후 진행한다. 현재 값은 2026-10-20 `miniapp_get` 조회 기준이다.

## 부제 (20자 이내, 느낌표·비속어 불가)

| 구분 | 문구 | 글자 수 |
| --- | --- | --- |
| 현재 | 냉장고 재료로 오늘 메뉴 찾기 | 16 |
| 제안 | 남은 재료로 오늘 메뉴 정하기 | 16 |

근거: "남은 재료"는 냉털(냉장고 털기)의 의미를 직접 설명하고, "정하기"는 앱의 핵심 가치(결정을 가볍게)와 맞다. 검색량 데이터는 없어 효과는 추정이다.

## 키워드

현재 6개: 냉털픽, 냉장고, 재료, 식재료, 요리, 음식. 허용 최대 개수는 미확인이다.

| 후보 | 이유 | 상태 |
| --- | --- | --- |
| 레시피 | 요리 검색의 기본 표현 | 추가 후보 |
| 냉장고파먹기 | 같은 행동을 가리키는 흔한 표현 | 추가 후보 |
| 냉파 | 위의 줄임말 | 추가 후보 |
| 오늘뭐먹지 | 메뉴 결정 의도의 검색 표현 | 추가 후보 |
| 메뉴추천 | 앱 기능 그대로 | 추가 후보 |
| 남은재료 | 부제와 일관 | 추가 후보 |
| 자취요리 | 주요 사용자(1인 가구) 표현 | 추가 후보 |
| 식재료, 음식 | 범위가 넓어 경쟁이 크고 의도가 약함 | 교체 후보 |

실제 검색어 통계를 확인할 수단이 없으므로 위 후보는 가설이다. 적용 후 검색 유입을 비교한다.

## 상세 설명 (500자 이내, 이모지 없음)

제안:

> 냉털픽은 냉장고에 남은 재료를 고르면 지금 만들기 좋은 메뉴를 하나 골라 알려주는 앱이에요. 재료를 카테고리별로 고르고 메뉴 뽑기를 누르면, 선택한 재료로 바로 만들 수 있는 메뉴를 먼저 보여줘요. 재료가 조금 모자란 메뉴는 따로 안내하고 더 준비할 재료를 알려줘요. 마음에 들지 않으면 같은 재료로 다시 뽑을 수 있어요. 난이도와 재료 매칭률로 후보를 좁힐 수 있고, 원문 재료 분량과 조리 순서, 출처도 확인할 수 있어요. 선택한 재료와 설정은 앱을 실행하는 동안 유지되고, 다시 실행하면 처음부터 시작해요.

변경 이유: 현재 문장은 내부 동작(필요 재료 기준, 원문 확인 안내)이 먼저 나오고 "초기화됩니다"로 끝난다. 가치를 먼저, 제약은 마지막에 둔다. 현재 정책(실행 중 유지·재실행 초기화)과 사실이 일치한다.

## 적용 전 확인할 것

- 글자 수 검사(2026-10-20): 부제 16자, 상세 설명 286자(500자 이내), 이모지·느낌표 없음.
- 콘솔 변경은 검수 재요청이 필요할 수 있다. 영향은 미확인이다.
- 변경 날짜를 기록해 이후 검색 유입을 비교한다(TASK-08).

## 2026-10-20 검토 요청 직전 수정안 (최신, 콘솔 미적용)

앞의 초안은 양념 가정·공유·결과 화면 배너가 구현되기 전에 쓴 것이다. 현재 구현에 맞춘 문구는 다음과 같다. 적용·제출은 사용자가 직접 한다.

- **상세 설명을 반드시 고친다.** 현재 콘솔 문구("등록된 필요 재료가 모두 선택되고 … 메뉴를 먼저 보여주며")는 기본 양념 9개를 선택 없이 있다고 보는 현재 동작과 다르다.

제안(356자, 500자 이내, 이모지·느낌표 없음):

> 냉털픽은 냉장고에 남은 재료를 고르면 지금 만들기 좋은 메뉴를 하나 골라 알려주는 앱이에요. 재료를 카테고리별로 고르고 메뉴 뽑기를 누르면, 선택한 재료로 만들 수 있는 메뉴를 먼저 보여줘요. 소금·설탕·후추·식용유·간장·참기름·고춧가루·참깨·식초는 선택하지 않아도 집에 있다고 보고 찾고, 결과에서 따로 확인할 수 있어요. 재료가 더 필요한 메뉴는 필요한 재료와 함께 안내해요. 마음에 들지 않으면 다시 뽑을 수 있고, 난이도와 재료 매칭률로 후보를 좁힐 수 있어요. 원문 재료 분량과 조리 순서, 출처를 확인하고 결과를 친구에게 공유할 수 있어요. 선택한 재료와 설정은 앱을 실행하는 동안 유지되고, 다시 실행하면 처음부터 시작해요.

출시 노트 제안(검토 요청 시 입력, 255자):

```
1. 소금·설탕·후추 등 기본 양념 9개는 선택하지 않아도 있다고 보고 추천해 바로 만들 수 있는 메뉴가 더 많이 나와요
2. 결과 화면에 집에 있다고 가정한 양념을 따로 확인하는 영역을 추가했어요
3. 추천 결과를 재료·조리 순서와 함께 친구에게 공유할 수 있어요
4. 결과 화면의 공유하기·처음부터 버튼을 한 줄에 나란히 배치했어요
5. 달걀 노른자·흰자, 통마늘, 배춧잎 표기를 인식하도록 개선했어요
6. 추천 결과 화면 하단에 배너 광고를 추가했어요
```

선택 사항: 부제("냉장고 재료로 오늘 메뉴 찾기", 16자)와 키워드는 지금도 사실과 어긋나지 않는다. 검색 노출 개선용 변경안은 위 초안을 참고하되 효과를 비교하려면 번들 검수와 분리해 따로 바꾸는 편이 낫다. 주요 기능 3개(재료 선택·메뉴 추천·레시피 확인)도 사실과 맞다.

제출 전 확인: 번들은 20261020-30(실제 광고, 결과 화면 하단 배너 포함)이어야 한다. 20261020-29에는 결과 화면 배너가 없다.
