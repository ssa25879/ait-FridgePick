해석: 전체 선택 기준 준비 완료는 늘었지만 일상 조합의 "바로 만들 수 있는 메뉴"는 여전히 0이다. 일상 조합이 막히는 주된 이유는 이번 묶음이 아니라 육수·기름·호박·물 같은 보존 이름과 레시피가 요구하는 재료 수다. 합성 조합 결과이며 실제 사용자 효과로 일반화하지 않는다.

자동 검증(2026-10-12): `npm test` 15파일/201개 통과(신규 22개 포함), `npm run test:scripts` 10개 통과, `npm run lint` 오류 0·기존 경고 1개(useInAppAds), `npm run build` 성공(AIT deploymentId 01a12e73…). 기존 테스트 3건은 재료 수 기대값 95→110과 샐러리 예시 교체로 갱신했고, 일부 jsdom 흐름이 5초 기본 제한에 근접해 `vite.config.ts`에 `testTimeout: 15000`을 추가했다. 브라우저(320×640): 칩 110개(채소·과일 44/단백질 18/계란·유제품 6/탄수화물 14/양념 28), 가로 넘침 없음.
