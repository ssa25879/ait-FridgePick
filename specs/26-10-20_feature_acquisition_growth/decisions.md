# 결정·미확정

## 사용자 결정이 필요한 항목

0. ~~본인 방문 구분~~: 해소(2026-10-20). 사용자가 기록된 방문은 전부 본인이 아니라고 알렸다. 기준선은 외부 약 5명으로 둔다. "일단"이라는 전제이므로 번복되면 validation.md 기준선을 재계산한다.
1. **성공 기준**: 몇 주 안에 어떤 지표를 얼마로 볼지. 현재 기준선이 약 5명이라 임의 수치를 쓰지 않았다. 제안: 먼저 2주간 1~2단계만 적용해 기준선을 만들고 그 뒤 목표를 정한다.
2. ~~연령 제한 19~99~~: 취소. 미니앱은 19세 이상에게 배포된다는 사용자 정정(2026-10-20).
3. **공유 메시지에 메뉴명을 넣을지**: 공유 전환에는 유리하나 사용자가 버튼을 눌렀을 때만 쓴다는 원칙으로 설계했다.
4. **알림 도입 여부**: 추천 미니앱 UX 원칙은 불필요한 알림 동의를 빼라고 한다. 지표로 필요성을 확인하기 전에는 도입하지 않는 쪽을 제안한다.
5. **사업자 등록**: 프로모션·비즈월렛의 선결 조건이다. 현재 사용자 결정은 "나중에 진행"이며 유지한다.

## 구현 중 내린 가정 (사용자 확인 필요)

- 리뷰 요청 시점: 바로 만들 수 있는 메뉴를 2번째 볼 때. 만족을 직접 측정할 수 없어 "다시 뽑아 볼 만큼 쓴 사용자"를 대리 지표로 삼았다. 근거 데이터는 없다.
- 공유 메시지에 메뉴 이름을 넣는다(결정 3번의 제안대로). OG 이미지는 쓰지 않는다.
- 공유 시트 취소는 오류 안내를 띄우지 않는다. SDK가 취소와 실패를 구분하는지는 미확인이다.

## 확정된 제약

- 로그인·서버를 추가하지 않는다(mission.md).
- 첫 진입에 로그인·알림 동의를 요구하지 않는다.
- 실제 광고 ID는 문서·로그에 쓰지 않는다.

## 확인하지 못한 사실

| 항목 | 이유 | 확인 방법 |
| --- | --- | --- |
| 현재 평점·리뷰 | 이번 조회 도구 오류. 10-12 기록은 평균 5점·리뷰 1개 | 콘솔 "평점 및 리뷰" 화면 |
| 전환 지표 등록 여부 | 조회 도구 호출 오류 | 콘솔 전환 지표 설정 화면 |
| 푸시 알림 동의 설정 상태 | 도구 파라미터 오류로 미조회 | 콘솔 알림 메뉴 |
| 키워드 최대 개수 | 문서에서 못 찾음 | 콘솔 입력 화면 |
| 검색 유입 키워드·노출 수 | 사용 가능한 조회 도구 없음 | 콘솔 지표 화면 |
| 평균 세션 단위 | 응답에 단위 없음 | 콘솔 화면 대조 |
| OG 이미지 외부 접근 | 호스팅 경로 미확인 | 구현 시 확인 |

## 프로모션 재개 조건

사업자 등록 완료, 프로모션 약관 동의, 비즈월렛 충전(최소 5만 원), 중복 참여·어뷰징 방지 로직 설계, 그리고 1~3단계로 기준선이 생긴 뒤.
