# 결정 기록: 추천 필터와 레시피 출처 각주

## 확정 사항

### 1. 매칭률은 최소 허용 기준으로 조절

- 결정: 사용자가 고른 60~100% 기준 이상인 레시피를 추천 후보로 만든다. 기본값은 현재 60%이며 입력 단위는 5%다.
- 근거: 기존 MVP 후보 기준을 유지하면서 사용자가 추천 폭과 보유 재료 적합도를 직접 조절할 수 있다.

### 2. 난이도는 단계·필수 재료 수 기반의 추정값

- 결정: 쉬움은 단계 ≤6 및 필수 재료 ≤6, 보통은 그보다 복잡하면서 두 수 모두 ≤10, 어려움은 어느 하나라도 10 초과로 정한다.
- 근거: 제공 CSV에 공식 난이도 필드가 없다. 현재 정규화 코드가 출처 근거 없이 공개 레시피를 모두 `normal`로 지정하므로 그 값을 실제 난이도로 유지하지 않는다.
- 범위: 전체 필수 재료 수에는 미지원 필수 재료를 포함하고 선택 재료는 빼서, 추천 매칭률 계산의 재료 범위와 일치시킨다.
- 카탈로그 관찰: 위 경계를 현재 공개 레시피 888개에 적용하면 쉬움 105개, 보통 336개, 어려움 447개다. 실제 조리 난이도에 대한 사용자 평가 결과가 아니라 단계·재료 수를 이용한 휴리스틱 분포다.

### 3. 두 필터는 동시에 적용

- 결정: 매칭률 기준과 난이도 선택을 각각 적용한 뒤 교집합만 후보로 남긴다. 기본 난이도는 전체다.
- 근거: 사용자가 지정하지 않은 난이도로 후보가 사라지는 동작을 피하고, 필터 의도를 그대로 반영한다.

### 4. 출처 각주

- 결정: 제공기관·데이터셋·원본 ID를 결과 맨 아래 13px 보조 텍스트로 보존한다.
- 근거: 이용자가 출처를 찾을 수 있게 유지하면서 메뉴명, 보유 재료, 부족 재료와 조리 단계보다 시각적 우선순위를 낮춘다.

### 5. 추천 설정 수명

- 결정: 화면 왕복과 재료 수정에서는 선택한 필터를 유지하고 `처음부터`를 누르면 재료와 함께 60%·전체 기본값으로 초기화한다.
- 근거: 기존 `처음부터`는 새 선택 흐름을 시작하는 초기화 버튼이고, 결과를 수정할 때에는 방금 조정한 조건을 유지해야 한다.
