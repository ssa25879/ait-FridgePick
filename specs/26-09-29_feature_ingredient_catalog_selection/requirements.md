# 요구사항: 재료 카탈로그와 선택

## 목적

사용자가 냉장고에 있는 재료를 카테고리별로 빠르게 찾고 여러 개 선택할 수 있게 한다. 제품 목표와 사용자는 [`specs/mission.md`](../mission.md)를 따른다.

## 범위

### 포함

- 다섯 재료 카테고리와 타입을 정의한다.
- 안정적인 재료 ID를 사용하는 로컬 초기 카탈로그를 제공한다.
- 카테고리별로 재료를 탐색하고 재료를 다중 선택·해제한다.
- 선택된 재료와 전체 선택 개수를 표시한다.
- 홈으로 이동한 뒤 재료 선택 화면으로 돌아와도 선택 상태를 유지한다.
- 320 CSS px 이상 폭과 키보드 입력에서 사용할 수 있게 한다.

### 제외

- 레시피 타입·레시피 데이터·메뉴 추천 계산
- 메뉴 뽑기 버튼과 결과·빈 결과 화면
- 앱 재시작 후에도 유지되는 저장, 로컬 스토리지, 계정·서버
- 알레르기, 제외 재료, 카테고리 편집, 검색·정렬
- 로드맵 1단계의 결과 화면 상태와 결과에서 홈으로 복귀하는 흐름

## 카테고리와 데이터 계약

| 타입 값 | 화면 표시명 |
| --- | --- |
| `vegetable` | 채소 |
| `meat` | 고기 |
| `eggDairy` | 계란·유제품 |
| `carb` | 탄수화물 |
| `seasoning` | 양념 |

프로젝트 기획서의 기존 타입 초안을 따른다.

```ts
type IngredientCategory = "vegetable" | "meat" | "eggDairy" | "carb" | "seasoning";

type Ingredient = {
  id: string;
  name: string;
  category: IngredientCategory;
};
```

`id`는 소문자 ASCII snake_case로 정하고 전 카탈로그에서 고유·안정적으로 유지한다. 화면에 보이는 한국어 이름을 ID로 사용하지 않는다.

## 초기 카탈로그 제안

아래 28개 항목을 첫 로컬 카탈로그로 사용한다. ID는 화면 문구나 카테고리가 바뀌어도 유지한다.

| 카테고리 | 재료 ID | 화면 표시명 |
| --- | --- | --- |
| 채소 | `kimchi`, `onion`, `green_onion`, `garlic`, `carrot`, `potato`, `zucchini`, `mushroom` | 김치, 양파, 대파, 마늘, 당근, 감자, 애호박, 버섯 |
| 고기 | `pork`, `beef`, `chicken`, `ham`, `bacon` | 돼지고기, 소고기, 닭고기, 햄, 베이컨 |
| 계란·유제품 | `egg`, `milk`, `cheese`, `butter` | 달걀, 우유, 치즈, 버터 |
| 탄수화물 | `cooked_rice`, `ramen_noodles`, `pasta`, `bread`, `glass_noodles` | 밥, 라면, 파스타면, 식빵, 당면 |
| 양념 | `soy_sauce`, `gochujang`, `doenjang`, `sesame_oil`, `cooking_oil`, `salt` | 간장, 고추장, 된장, 참기름, 식용유, 소금 |

## 기능 요구사항

| ID | 요구사항 | 완료 조건 |
| --- | --- | --- |
| ING-01 | 재료 타입과 카테고리를 명시적으로 정의한다. | 카탈로그 항목 모두 `id`, `name`, `category` 타입을 만족한다. |
| ING-02 | 위 초기 카탈로그를 앱 내부 로컬 데이터로 제공한다. | 28개 ID가 고유하고 각 재료가 정확히 한 카테고리에 속한다. |
| ING-03 | 카테고리별 재료 목록을 탐색한다. | 다섯 카테고리가 정해진 순서와 한국어 이름으로 표시되고, 활성 카테고리의 재료만 목록에 보인다. |
| ING-04 | 재료를 여러 개 선택·해제한다. | 재료를 누르면 선택 상태가 켜지고 다시 누르면 꺼진다. 한 번에 여러 재료를 선택할 수 있다. |
| ING-05 | 선택 상태를 확인한다. | 전체 선택 개수와 선택한 재료 이름이 활성 카테고리와 무관하게 보인다. 선택이 없으면 0개를 표시한다. |
| ING-06 | 화면을 이동해도 현재 선택을 유지한다. | 홈으로 갔다가 선택 화면으로 돌아오면 같은 재료 ID 목록이 선택되어 있다. |
| ING-07 | 선택은 앱 실행 중 메모리에서만 유지한다. | 앱을 새로고침하거나 다시 실행하면 선택은 초기화된다. 영속 저장을 추가하지 않는다. |
| ING-08 | 작은 화면과 키보드 입력을 지원한다. | 320 CSS px에서 가로 넘침이 없고 모든 선택 버튼을 Tab, Enter, Space로 사용할 수 있다. |

## 완료 조건

- 다섯 카테고리와 28개 로컬 재료가 화면에 표시된다.
- 카테고리 전환 후에도 선택 상태와 전체 개수가 일치한다.
- 선택·해제가 반복 가능하고 선택한 이름을 확인할 수 있다.
- 홈 이동 후 돌아오면 선택이 유지되고, 전체 앱 새로고침 뒤에는 초기화된다.
- 320 CSS px에서 카테고리·재료·선택 요약이 가로로 잘리지 않는다.
- `npm run lint`와 `npm run build`가 종료 코드 0으로 끝난다.
