# 요구사항: 재료 화면 조건부 배너

상위: [로드맵 11단계](../roadmap.md), 출시 준비 RCR-05·06·09. 구현 기준: 3a9972c.

| ID | 요구사항 | 완료 조건 |
| --- | --- | --- |
| IB-01 | 노출 화면 제한 | 재료 선택 화면만 허용하고 홈·추천 결과·빈 결과에서는 부착하지 않는다 |
| IB-02 | 실제 콘텐츠 스크롤 조건 | 광고와 광고 앞 간격을 제외한 콘텐츠 하단 문서 좌표+조상 bottom padding > innerHeight+1일 때만 부착한다 |
| IB-03 | 변경 시 재판정 | 콘텐츠/문서 ResizeObserver와 window resize로 판정하며 조건 소멸 시 해제, 충족 시 재부착한다 |
| IB-04 | CTA·광고 분리 | 메뉴 뽑기 아래 일반 흐름에 1개, CTA 간격32px, 너비100%·높이96px. fixed·광고용 빈 콘텐츠 없음. 실제 Ad 표기와 터치 적합성은 기기로 확인한다 |
| IB-05 | 수명·SDK 경계 | 초기화와 지원 검사 후 표준 TossAds로 부착하고 이탈/언마운트/조건 소멸 시 destroy한다 |
| IB-06 | 실패 시 핵심 기능 유지 | no-fill·렌더 실패는 슬롯을 접고 추천 CTA는 사용 가능. ResizeObserver 미지원이면 배너 없이 사용한다 |
| IB-07 | 테스트/출시 구분 | 기본 빌드는 공식 테스트 ID, release는 기존 출시 ID 분기. 실제 ID 값은 문서에 적지 않는다. 원격 비노출 목표 미달성은 RCR-14로 남긴다 |
| IB-08 | 완료 수준 구분 | 코드·자동·브라우저 결과와 기기·검수 결과를 구분하며 실제 토스 QA 전 전체 정책 충족을 선언하지 않는다 |

제외: 광고용 콘텐츠 확장, SDK UI/이벤트 변조, 광고 클릭 유도, 다른 광고 포맷 연결, 콘솔 업로드·출시, 기존 원격 이력 변경.
