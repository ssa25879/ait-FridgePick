# 추천 결과 흐름과 메뉴 후보 계산

- 상태: 1·4·5·6단계 구현·자동/모바일 검증 및 심층 리뷰 완료
- 작성일: 2026-09-29
- 개발 브랜치: `feature/result-navigation-recommendation`
- 로드맵: [`specs/roadmap.md`](../roadmap.md) 1단계 미완료 항목, 4단계

## 목표

홈·재료 선택·결과 화면 상태를 연결하고, 선택 재료에 맞는 레시피 후보와 추천 한 건을 계산한다. 결과에는 보유·부족 재료와 조리 단계를 표시하고, 다시 뽑기·처음부터·홈 이동을 제공한다. 빈 재료·후보 없음·단일 후보 상태를 구분해 안내한다.

## 현재 상태와 남은 범위

기획서의 초기 후보 제안값을 확정해 필수 재료 매칭률이 60% 이상인 레시피만 후보로 사용한다. 계산 결과에는 보유·부족 필수 재료 ID와 매칭률이 포함된다. 후보가 여럿이면 무작위로 한 개를 선택하고, 다시 뽑을 때 직전 결과를 제외한다.

결과 화면은 메뉴명과 매칭률, 보유·부족 재료 이름, 조리 단계, 다시 뽑기, 처음부터 초기화, 홈 복귀를 제공한다. 재료 0개·후보 0개·후보 1개·후보 여러 개 안내와 320×640 CSS px 화면 확인도 포함한다. 화면 전환 초점, 간결한 결과 안내, 44px 터치 영역을 리뷰 후 보완했다. 실제 앱인토스 미니앱 실행은 별도 확인이 필요하다.
