# 검증

문서 준비, 코드 구현, 자동 검증, 브라우저 모의 검증, 토스 실기기 검증, 콘솔 검수·출시를 구분한다. 수행하지 않은 항목은 완료로 표시하지 않는다.

## 이번 준비에서 확인한 것

| 항목 | 상태 | 근거 |
| --- | --- | --- |
| 현재 규칙에서 준비 완료가 거의 나오지 않음 | 확인(합성 데이터) | 2026-10-20 임시 측정, 재료 5/8/12/16개에서 0개인 비율 98/99/95/89% |
| 양념 가정 시 예측 | 확인(합성 데이터) | 같은 측정에서 평균 1.3/2.1/4.1/6.9개, 0개인 비율 27/10/2/0% |
| 가정만으로 준비 완료 가능한 레시피 수 | 확인 | 1,359개 중 최대 239개(미지원 재료 82%가 남음) |
| 임시 측정 파일 | 삭제 | 저장소에 남기지 않음 |

측정의 한계: 냉장고는 레시피 사용 빈도에 비례해 무작위로 만든 합성이며 실제 사용자 선택이 아니다. 양념은 선택 풀에서 제외했고, 가정 대상은 양념 카테고리 33개 전체다.

## 구현 단계 검증 계획

| 테스트 | 대응 | 방법 |
| --- | --- | --- |
| TEST-01 양념만 부족하면 준비 완료 | SAS-01 | `recipeReadiness` 단위 테스트 |
| TEST-02 후보 ID 집합·매칭률 불변 | SAS-02 | 변경 전후 같은 입력 비교 테스트 |
