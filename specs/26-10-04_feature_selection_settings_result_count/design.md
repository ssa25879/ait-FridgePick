# 설계

`usePersistentUserState`의 기존 사용자키·직렬 저장을 재사용한다. 저장 상태를 추가하고 최신 저장 요청의 완료만 UI에 반영한다. 조회 실패/1500ms 초과/미지원이면 세션 유지 안내를 표시한다. 영속 저장 성공 여부는 `saveUserState`의 boolean 결과로 판단한다.

재료 화면의 필터와 선택 설정을 기본적으로 접힌 details 안에 배치한다. summary는 현재 매칭률·난이도와 “필터·저장 설정”을 표시한다. 접기/펼치기는 조회·저장을 새로 호출하지 않는다. 초기화 버튼은 같은 영역에 취소/초기화하기 확인 버튼을 펼친다. 모달·브라우저 confirm 없이 TDS 버튼으로 확인하며 확인 후 원래 초기화 버튼으로 포커스를 복귀한다.

App의 기본값 초기화 함수를 재사용한다. 결과 화면의 기존 처음부터 흐름도 유지한다. 결과 개수는 App이 계산한 `candidates.length`를 기존 `candidateCount` 속성으로 전달받아 표시하며 검색 로직을 중복하지 않는다.

CSS는 기존 필터 카드·15px 본문·44px 버튼 기준을 따른다. 선택 설정을 광고 측정용 서비스 콘텐츠 내부에 배치한다. 광고 높이 자체가 스크롤 조건을 만들지 않는 기존 계약을 유지한다.

카테고리 필터 타입만 all을 허용한다. 실제 재료 데이터의 category 타입은 기존5종을 유지하며 all이라는 재료 카테고리를 만들지 않는다. 전체 탭은 기존95개 목록을 그대로 표시한다. accessible name은 “전체 재료”로 난이도 전체와 구분한다.

카테고리를3열·2줄로 표시하고 카드 여백·콘텐츠 gap을 줄인다. 결과의 별도0개/1개 안내를 제거해 하단 검색 개수 문단 한 곳으로 통일한다. 큰 CTA는large, 초기화 버튼은small을 사용하되44px 이상의 터치 높이를 유지한다. 전체95개를 펼친 화면은 목록 자체가 길어질 수 있으므로 스크롤 감소 비교는 기본 채소 탭의 동일한 빈 선택 상태로 수행한다.

## SSC-08 재료 목록

필터 details를 카테고리 앞에 배치한다. ingredient-scroll-viewport는 max-height clamp(176px,34dvh,280px), overflow-y:auto와 키보드 포커스를 사용한다. 제목/칩은 가운데 정렬하고 카테고리별 key로 목록의 스크롤 위치만 초기화한다. 터치44px·본문15px를 유지한다. 광고 판단은 기존 전체 화면의 콘텐츠 넘침 기준을 유지하며 내부 목록의 scrollHeight만으로 광고를 활성화하지 않는다.
