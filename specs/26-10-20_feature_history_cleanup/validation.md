# 검증

문서 준비, 백업, 연습, 원격 변경, 전환, 삭제를 구분한다. 수행하지 않은 항목은 완료로 표시하지 않는다. 각 게이트는 아래 항목이 **모두** 통과해야 열린다.

## 게이트 G1 (세션 1 끝)

| 번호 | 확인 | 방법 | 대응 요구사항 | 상태 |
| --- | --- | --- | --- | --- |
| V1 | 백업 번들이 유효하다 | `git bundle verify` 통과 | HC-01 | 미수행 |
| V2 | 백업에 로컬 전용 브랜치 3개·스태시·원격 추적 참조가 있다 | `git for-each-ref` 목록 대조, `stash0.patch` 존재 | HC-01 | 미수행 |
| V3 | 외부 사본의 SHA256이 같다 | `sha256sum` 비교 | HC-01 | 미수행 |
| V4 | 정리본의 모든 참조·커밋에서 ID 0건 | `log --all -S`, 커밋별 `git grep` 둘 다 0줄 | HC-02 | 미수행 |

| V6 | 정리본 `master` 끝의 `npm ci`·`tsc -b`·`npm test`·`npm run test:scripts`·기본 빌드 통과 | 명령 실행 | HC-04 | 미수행 |
| V7 | 일반 비밀 패턴(키·토큰·비밀번호·개인 키·서명 URL) 검색 결과를 기록 | 이력 전체 검색 | HC-02 | 미수행 |
