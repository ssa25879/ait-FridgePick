## 현재 데이터 결과

- 원본: 1,156행·55열. 원본 ID 1,156개 모두 고유.
- 정규화: 881개 포함, 275개 제외(매핑률 미달 261, 매핑 재료 없음 13, 조리 단계 없음 1).
- 카탈로그: 기존 수기 레시피 20개와 공개 레시피 881개, 총 901개. 재료 100개.
- 추천 비교: 대표 선택 10개는 후보 없음 비율이 50%로 동일했다. 단백질 1·채소 2·탄수화물 1·계란/유제품 1개를 균등 표본으로 만든 100개 입력에서는 94%에서 83%로 감소했다. 실제 사용자 선택 분포를 측정한 값은 아니며, 데이터 추가만으로 추천 공백이 해결됐다고 보지 않는다.
- 빌드 크기: 기준 AIT 파일 715,371바이트, 변경 AIT 파일 958,299바이트. 상세 수치는 `validation.md`에 기록했다.
- CSV 조리 단계 중 문장부호 뒤에 붙은 표시용 `a`~`d` 접미 17건을 정규화 과정에서 제거하고 회귀 테스트로 확인했다.
