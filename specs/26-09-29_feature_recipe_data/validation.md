# 검증 계획: 레시피 데이터

## 기준 상태

- 화면은 변경하지 않았으므로 모바일 화면 수동 검증은 해당하지 않는다.
- 앱인토스 번들은 로컬에서 컴파일했으며 배포·실기기 확인은 하지 않았다.
- 레시피는 자동 검사에서 20개로 확인했다.
