## 기준선 (2026-10-20 조회, 2026-10-06~10-20, 모두 외부 방문으로 가정)

| 지표 | 값 |
| --- | --- |
| 고유 사용자 | 5명 추정(신규 합). 일별 활성의 합은 6이고 콘솔 OS·연령 분해 합도 6이라 1명 차이는 일별 중복(재방문 1명)으로 본다. 콘솔 정의는 미확인 |
| 일별 활성 | 10/6 2명, 10/7 1명, 10/12 3명, 나머지 12일 0명 |
| 신규 | 10/6 2명, 10/7 1명, 10/12 2명 (합 5) |
| 재방문 | 10/6 유입 중 1명이 6일 뒤(10/12) 방문. D1~D5는 모두 0% |
| 유입 | 검색 2(10/12), 전체탭 2, 기타 4 (일별 활성 기준) |
| 페이지뷰 | 합 23 (10/6 5, 10/7 1, 10/12 17) |
| 평점 | 평균 5점, 리뷰 1개 (Task.md 10-12 기록, 재조회 못 함) |

해석 한계: 표본 5명 안팎에서 D1 0%는 우연과 구분되지 않는다. 가설 검증에는 최소 수십 명 규모가 필요하며, 지금은 "측정 도구와 노출 경로를 먼저 만든다"는 판단만 지지한다. 유입 경로 수치(10/12 검색2·기타2·전체탭1 = 5)는 같은 날 활성 3명보다 커서 사용자 수가 아니라 진입(세션) 수일 수 있다. 경로별 사용자 수로 해석하지 않는다.
