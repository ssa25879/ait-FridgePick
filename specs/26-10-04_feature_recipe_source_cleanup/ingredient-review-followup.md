# RSC-12 추가 원문 대조

후속: [식약처 원본 복구와 보류 재료 추가 대조](./source-recovery-review.md)에서2개오탈자매핑과3개확인안내를추가했다. 현재안내72개이며아래69개/보류목록은그이전점검기록이다.

검증일: 2026-10-05. 로드맵 13단계 / Task 목록 6번. 입력 파일·해시와 기존 8개 근거는 [ingredient-review.md](./ingredient-review.md)에 기록했다.

## 범위와 판정

EPIS 471개에서 선택 재료명(2글자 이상, 복합 표시 제외)과 육수·계란 표기가 원문 목록에 없고 조리 본문에 등장하는 경우를 검색했다. 팁 본문은 제외했다. 검색 후보 106개 중 기존 8개와 아래 추가 61개의 불일치를 확인해 안내 대상은 총 69개다. 검색 결과 자체를 누락 판정으로 사용하지 않고 실제 재료 JSON 행과 과정 CSV의 단계 문맥을 대조했다.

물·기름 같은 일반 표현, 모든 동의어와 복합 재료는 포괄하지 않는다. 이 표는 확인된 불일치의 근거이며 각 메뉴의 모든 누락을 찾았다는 뜻이 아니다. 재료 목록의 밀가루/피망/만두피와 단계의 찹쌀가루/홍고추/직접 반죽처럼 서로 다른 입력을 요구하는 경우도 안내한다. 원문 재료·분량·필수 ID는 수정하지 않는다.

## 검증과 후속

새 불일치 안내 검사 1개가 변경 전에 실패하고, 구현 후 파생/대체법 오탐 방지와 원문 보존을 포함한 관련 3파일 40개가 통과했다. 총 카탈로그 1359개, 95개 전체 선택/기본 60% 후보 940개·준비 완료 138개·준비 필요 802개는 유지한다. 추가 61개는 기존 미지원 필수 재료 등의 이유로 이미 준비 필요 그룹에 있었으며, 이번에는 정확한 원문 확인 사유를 표시한다. 실제 사용자 보유량과 조리 성공률을 검증한 수치는 아니다.

식약처 원본 888개/기준일은 여전히 미확보다. 실기기는 최종 번들에서 통합 확인한다. 다음은 로드맵 12단계의 최종 번들·기기 QA와 로드맵 13단계의 동일 기능 성능 비교 쌍 준비다. 복합 재료/오탈자 교정은 출처 확인 후 별도 보완한다.
