# 결정·미확정 사항

## 확정(기존 결정 유지)

- 기본 매칭 기준 60%, 주재료 중심 매칭, 준비 완료 우선 추천, 양념 자동 보유 금지, 원문 분량·순서·출처 보존. 근거: [RSC 요구사항](../26-10-04_feature_recipe_source_cleanup/requirements.md) RSC-08·11.
- 모호한 재료는 임의로 통합하지 않는다.

## 사용자 결정 (2026-10-12: 제안대로 진행)

1. 새 선택 재료 추가 범위: 빈도 상위(굴소스·샐러리·토마토케첩·상추·김 등)를 몇 개까지 추가할지. 칩이 늘면 화면이 길어진다. 제안: 첫 묶음 10~15개, 효과를 재측정한 뒤 추가 여부 결정.
2. 육수(53)·기름(32): "육수"를 선택 재료나 자동 보유로 볼지, 계속 "추가 준비"로 둘지. 제안: 양념 자동 보유 금지 원칙에 따라 자동 보유 처리하지 않고, 필요 시 선택 가능한 "육수" 재료만 추가.
3. 호박(21)처럼 애호박·단호박·늙은호박이 섞이는 이름: 제안은 보존(미지원 유지). 원문 문맥으로 구분되는 경우만 개별 매핑.
4. 한 번에 반영할지, 효과를 보며 2~3회로 나눠 반영할지. 제안: 분할.
5. 새 번들을 올려 라이브에 반영할지 여부와 시점. 제안이 없었으므로 **업로드·출시는 결정되지 않았고 하지 않는다.**

사용자는 1~4번을 제안대로 진행하라고 답했다(첫 묶음 15개 이하, 육수 자동 보유 금지, 호박 보존, 분할 반영).

## 1차 분류·반영 결과 (RGC-02·03)

빈도 상위 미지원 이름 중 하나로 단정할 수 있는 표기만 정확히 일치(공백 제거 후)로 연결했다. 부분 일치는 쓰지 않는다(예: 김↔김치, 새우젓↔새우젓국, 튀김가루↔튀김은 연결하지 않음).

| 구분 | 이름(원문 빈도) |
| --- | --- |
| (가) 기존 재료 별칭 | 스파게티(12)→파스타면 |
| (나) 새 선택 재료 15개 | 굴소스(24)·케첩(토마토케첩 22+케첩 17)·셀러리(샐러리 23+5)·상추(21)·김(20)·홍합(19)·밤(19)·새우젓(15)·들깻가루(15+11)·튀김가루(16)·고사리(15)·도라지(14)·머스터드(13)·고등어(13)·떡(떡볶이떡 12+가래떡 12 등) |
| (다) 보존 | 육수(53)·닭육수(17)·기름(32)·고추기름(10)·호박(21)·호박잎·새우젓국·꽃상추·허니머스터드·백김치·어린잎(17)·생강청(16) 등 |

다음 묶음 후보(2차, 결정 필요): 어린잎·어린잎채소, 모시조개, 치커리, 인삼, 우엉, 죽순, 생강청, 완두콩, 현미, 겨자, 전복, 낙지, 오레가노, 토마토소스, 실곤약. 원문 줄 근거 확인 후 같은 방식으로 진행한다.

## 미확인

- 로드맵 기록(1,215개)과 실측(1,218개) 차이의 원인.
- 실제 사용자 재료 조합 표본은 없다. 합성 조합으로 대신 통과 처리하지 않고 한계를 기록한다.
