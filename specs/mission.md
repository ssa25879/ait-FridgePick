# 냉털픽의 목표

## 한 문장 목표

냉장고에 남은 재료를 고르면, 지금 만들기 좋은 메뉴 하나를 빠르고 가볍게 추천한다.

## 해결할 문제

집에 식재료가 있어도 어떤 메뉴를 만들지 결정하기 어렵다. 냉털픽은 사용자가 가진 재료를 기준으로 가능한 메뉴 후보를 좁히고, 그중 하나를 골라 식사 결정을 돕는다.

## 주요 사용자

- 냉장고에 자투리 재료가 남은 1인 가구
- 간단한 한 끼를 준비하려는 학생·취업 준비생
- 재료 조합이나 요리가 익숙하지 않은 초보 사용자

## 사용자가 얻게 될 결과

사용자는 앱을 열고 재료를 선택한 뒤 추천 메뉴를 확인한다. 결과에는 레시피에 사용할 수 있는 보유 재료와 더 필요한 재료가 구분되어 나온다. 추천이 마음에 들지 않으면 같은 선택을 유지한 채 다시 뽑을 수 있다.

## 제품 원칙

1. **빠르게 고른다.** 보유 재료 선택은 약 10초 안에 끝나도록 단순하게 만든다.
2. **남은 재료를 활용한다.** 재료 선택이 추천 결과에 어떻게 반영됐는지 보유·부족 재료로 보여준다.
3. **결정을 가볍게 만든다.** 많은 후보를 비교하게 하기보다 메뉴 한 가지를 바로 추천한다.
4. **작고 안정적인 흐름에 집중한다.** MVP의 성공은 기능 수보다 재료 선택부터 추천까지 한 사이클을 짧고 안정적으로 완성하는 데 있다.

## MVP 목표

- 재료를 카테고리별로 여러 개 선택할 수 있다.
- 선택 재료를 바탕으로 추천 가능한 메뉴를 계산한다.
- 후보 중 한 가지를 무작위로 추천한다.
- 결과에서 보유 재료와 부족 재료를 구분한다.
- 다시 뽑기와 처음부터 기능을 제공한다.
- 서버 없이 프론트엔드만으로 핵심 흐름을 완성한다.
- 일반적인 사용 흐름을 약 30초~1분 안에 끝낼 수 있다.

## MVP에 포함하지 않는 목표

- 회원가입, 로그인, 서버, 데이터베이스
- 외부 레시피 API와 장보기·배달 연동
- AI가 새 레시피를 생성하는 기능
- 사용자 간 공유·소셜 기능
- 복잡한 영양 정보 계산

즐겨찾기, 알레르기·제외 재료, 조리 시간·난이도 필터 등은 MVP 사용성을 확인한 뒤 필요성이 있을 때 검토한다.

## 성공을 판단하는 기준

사용자가 재료를 고르고 추천 메뉴를 확인하는 과정이 단순하고 안정적이며, 추천 결과에서 가진 재료와 더 필요한 재료를 이해할 수 있으면 MVP의 핵심 목적을 달성한 것이다. 세부 완료 항목은 [`roadmap.md`](./roadmap.md), 요구사항 원문은 [`NaengteolPick_React_Project_Plan.md`](./NaengteolPick_React_Project_Plan.md)을 따른다.
