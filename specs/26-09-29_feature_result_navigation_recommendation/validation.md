## 실행 결과

- `npm test`: 5개 파일, 20개 테스트 통과.
- `npm run lint`: 종료 코드 0. 기존 `src/hooks/useInAppAds.tsx:54`의 `react(set-state-in-effect)` 경고 1건.
- `npm run build`: 종료 코드 0. TypeScript, Vite, AIT 빌드 성공. JS 번들 1,250.21 kB가 500 kB 기준을 넘는 Vite 청크 경고 1건.
- 모바일 화면: 로컬 인앱 브라우저를 320×640 CSS px로 두고 주요 화면과 결과 흐름을 확인했다. 결과 상세 문서는 320×840px이며 세로 스크롤로 이어진다. 문서 가로 폭은 320px로 넘침이 없다. 카테고리 버튼·재료 칩·결과 상단 홈 버튼은 각각 높이 44px이다.
- 접근성 수동 확인: 홈→재료→결과→홈 이동 후 새 화면의 main 영역에 초점이 이동한다. 결과 라이브 안내는 추천 메뉴명과 매칭률만 포함한다.
- 로컬 AIT 브리지 제한: 브라우저에는 호스트가 주입하는 `window.__appsInTossConstants`와 `window.__ait`가 없다. 따라서 TDS `SafeAreaInsets`가 상수를 읽는 콘솔 오류가 발생한다. 이전 재료 선택 기능의 검증 기록과 같은 환경 제한이며, 로컬 화면은 렌더링되지만 실제 Toss WebView의 안전 영역 동작을 검증한 것은 아니다.
- 앱인토스 실기기/미니앱 배포 확인은 이 로컬 미리보기에 포함되지 않는다.
- 세 관점 심층 리뷰의 지적 사항은 모두 조치했으며 결과는 [`review.md`](./review.md)에 기록했다.
